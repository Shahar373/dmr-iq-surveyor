Value is how unpredictable a measurement there would be. A place where a site is certainly heard, or certainly not, teaches nothing about where it is.

    A drive measures continuously and writes no IQ at all. Every 150 m of road becomes one virtual stop of about 8 KiB, so a whole campaign of driving costs a few megabytes — which is the reason this mode exists on a Pi.

    Each measurement covers the road it takes to gather ten windows — about 100 m crawling through a town, about 250 m on an open road — so every one averages the same amount of signal. It is clamped at both ends: below ~100 m two measurements are the same measurement, above ~250 m one measurement covers more ground than it can be pinned to. Road that has been measured is never measured again.

    Centre frequency and gain come from the Record tab — deliberately the same numbers a stationary stop uses, because levels measured with different gain are not comparable and a drive has to be comparable with the stops around it.

    Bins are written the whole time you drive. Solve now only decides when the map catches up with them — it costs the Pi a few seconds to a few minutes of CPU, which the receiver is competing with, so ask for it at a red light rather than mid-overtake.

    A stop can be set aside without losing it — its measurements stop counting and the reason is recorded. Delete only a stop that should never have existed.
